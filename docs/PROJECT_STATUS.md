# 项目状态

本页记录已经在真实设备上验证的能力、仍然存在的限制和后续方向。它不是兼容性承诺。

## 已验证

### ReOutlook

- Outlook Web、学校登录和 Duo/MFA；
- WebView Cookie 与站点会话延续；
- `FindConversation`、`GetConversationItems` 和 `GetItem` 结构化采集；
- 分页、限速历史回填、正文补取和最多 100 项的长会话扩展逻辑；
- 草稿排除、修订感知检查点和原生写入确认；
- 本地邮件列表与禁用网络的离线正文；
- PUID/SMTP 账号别名合并和 v2 → v4 无损数据库迁移；
- 管理员 RSA 签名、机主锁屏确认、加密导出与离线解密。

### ReBrowser

- WebView `MULTI_PROFILE` 支持探测；
- 同一总标签页内共享 Cookie、不同总标签页之间隔离 Cookie；
- 总标签页和子标签页双层模型；
- 临时、副、主生命周期以及副总标签页收起和恢复；
- 多个主总标签页并存、进程重启恢复和延迟 Profile 清理；
- 收藏夹与完整环境书签栏分离；
- `target=_blank` 和 `window.open` 在当前总标签页中创建子标签页；
- 桌面双入口、应用内模式切换和统一系统返回策略；
- ReBrowser 管理协议 v2：双永久根、三级授权、结构化结果、对象 ID 控制、加载等待、生命周期、诊断、审计及有界修复；
- WebView 原生全屏视频以及 Bilibili 电脑版视频播放；
- 全局方向切换、横屏全屏播放及退出全屏后的界面恢复。

当前主要测试设备使用 Google Android WebView 149.0.7827.48。运行时仍然保留功能检查；不支持 `MULTI_PROFILE` 的提供者不会启用 ReBrowser。

## 当前限制

- 项目没有接受独立安全审计；
- 第二个真实 Outlook 账号隔离尚未端到端验证；
- 超过 20 封邮件的真实长会话仍缺少样本验证；
- 远端删除、移动和复杂同步失败恢复仍需继续测试；
- ReBrowser 仍基于系统 WebView，不具备完整浏览器内核产品的全部能力；
- ReBrowser 管理接口仍是有界语义命令集，不提供任意脚本、数据库或私有文件访问；
- 新增的三段视频方向覆写已完成构建和设置界面检查，所有策略组合尚未逐项手工验证；
- 面向普通用户的显式备份与恢复尚未完成；
- 当前公开 APK 使用开发者 Debug 证书签名，不是长期生产发布密钥。

## 后续方向

1. 继续扩展 ReBrowser 管理协议的批处理、结果保留策略和更多安全状态修复；
2. 继续完善浏览器站点信息、收藏编辑、下载、分享、深色模式和受限历史恢复；
3. 讨论并设计无痕模式及其与命名 Profile 生命周期的关系；
4. 验证 Outlook 长会话、远端删除和第二账号隔离；
5. 将 SQLiteOpenHelper 数据访问层迁移到 Room；
6. 实现带同账号验证、加密和回滚保护的普通用户备份恢复；
7. 评估基于 GeckoView 与 Android Components 的下一代完整浏览器实现。
